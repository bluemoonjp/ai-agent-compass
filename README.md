# ai-agent-compass

## English

### What this is

Best practices for AI coding agents, distilled from primary sources and research, with machinery that keeps them from rotting. Read by agents; maintained by humans.

### Status

pre-alpha. The skeleton and its checks are being built first; content follows issue by issue.
