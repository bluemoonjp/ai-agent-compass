# Contributing

This repository is not yet accepting outside contributions. It is early:
content, conventions, and the check suite are still being built out by a
single maintainer, issue by issue.

External contributions will open once the pilot content set and the
authoring/review conventions in `docs/maintain/` are stable, and a revised
`CONTRIBUTING.md` describes the process (Issue Forms, CODEOWNERS, a
fork-PR path).

Until then, please open an issue instead of a pull request; a maintainer
will follow up.
